================================================================================
ARCHITECTURE (5 LAYERS)
================================================================================

Layer 1: Gap Analysis
  → Identify uncovered domains, prioritize by gap type

Layer 2: Repository Catalog (PRIMARY)
  → Query GoldCaseReferenceCatalog by domain
  → Return candidates ranked by priority
  → Results: REPRODUCIBLE ✓ DETERMINISTIC ✓ STABLE ✓

Layer 3: Fallback (Live Search)
  → Only if catalog empty
  → NOT reproducible until curated

Layer 4: Screening (5-Phase)
  → Objective evaluation, auto-progression

Layer 5: Curation Prep
  → Generate templates, stop (no persistence/lock/eval)

EXTENSIBILITY
================================================================================

Process to add new candidate:
  1. Live search discovers Candidate X
  2. Supervisor verifies source
  3. Add CatalogEntry to repository
  4. Commit to git
  5. Future runs discover it (reproducibly)

Code example:
  new_entry = CatalogEntry(
      catalog_id="CATALOG_007_NEW",
      taxon="New Candidate",
      source_reference_id="SOURCE_ID",
      # ... full metadata ...
      verification_status="CURATED",
  )
  GoldCaseReferenceCatalog.CATALOG.append(new_entry)
