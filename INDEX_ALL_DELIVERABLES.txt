================================================================================
MANDATORY VERIFICATION GATES (8)
================================================================================

1. SOURCE_NOT_FOUND → HALT
   Source document unretrievable

2. SOURCE_NOT_VERIFIED → HALT
   Metadata unverified against official records

3. EVIDENCE_NOT_VERBATIM → HALT
   Evidence doesn't support claimed assertion

4. METADATA_FABRICATED → HALT
   Hard-coded logic or fabricated metadata found

5. ENGINE_EVALUATION_FAILED → HALT
   Engine crashes or produces inconsistent output

6. TEST_INTEGRATION_FAILED → HALT
   Any integration test fails

7. REGRESSION_FAILED → HALT
   Any existing test fails

8. REPORT_VALIDATION_FAILED → HALT
   Reported metrics don't match artifacts

Result: NO case can reach SUPERVISOR_APPROVED if any gate fails


================================================================================
WHAT CANNOT HAPPEN ANYMORE
================================================================================

❌ Fabricated metadata
   (Verification module requires all fields verified or empty)

❌ Unverified sources
   (SOURCE_VERIFICATION gate prevents proceeding)

❌ Paraphrased text labeled VERBATIM
   (Extraction stage requires precise locators)

❌ Hard-coded applicability decisions
   (Case validator detects and halts)

❌ Tests testing case instead of engine
   (Integration test builder enforces real invocation)

❌ Circular tests
   (Tests must invoke actual production modules)

❌ Numerical inconsistencies in reports
   (Metrics calculated automatically)

❌ Cases without supervisor approval
   (State machine enforces SUPERVISOR_APPROVED state)

❌ Pipeline proceeding with missing pieces
   (Verification module requires completeness)
