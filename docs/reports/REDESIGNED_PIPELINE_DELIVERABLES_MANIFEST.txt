WHAT CANNOT HAPPEN WITH REDESIGNED PIPELINE
================================================================================

❌ Fabricated metadata
   (Verification module requires all fields verified or empty)

❌ Unverified source used
   (SOURCE_VERIFICATION gate prevents proceeding)

❌ Evidence labeled VERBATIM when paraphrased
   (Extraction stage requires precise locators for VERBATIM)

❌ Hard-coded applicability in case
   (Case validator detects and halts)

❌ Tests testing case instead of engine
   (Integration test builder enforces real engine invocation)

❌ Circular tests (hard-coded value = hard-coded value)
   (Tests must invoke real modules)

❌ Numerical inconsistencies in reports
   (Metrics calculated automatically, validated against artifacts)

❌ Cases reaching production without supervisor approval
   (SUPERVISOR_APPROVED state required)

❌ Pipeline proceeding with missing pieces
   (Verification module requires completeness)
